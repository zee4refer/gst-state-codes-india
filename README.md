# GST state codes of India (JSON + CSV)

The 2-digit **GST state codes** used as the first two characters of every GSTIN and for the *place of supply* on invoices – all states and union territories, plus 97 (Other Territory) and 99 (Centre Jurisdiction).

Try it online, no install: **[billingbazaar.in/tools/gst-state-codes/](https://billingbazaar.in/tools/gst-state-codes/)**

## Files

- `gst-state-codes.json` – `{"27": "Maharashtra", ...}`
- `gst-state-codes.csv` – `gst_code,state`

## Place of supply, filled in for you

Every GST invoice must show the place of supply, and it decides CGST + SGST (same state) or IGST (other state).
Billing software picks it from the customer's GSTIN or address so you never look up a code by hand – in **Vyapar**
it is set from the party's state ([setting up GST in Vyapar](https://billingbazaar.in/guides/how-to-set-up-gst-in-vyapar/)).
